# 美股定投助手 (US ETF DCA Assistant)

**美股定投助手** 是一款专为长期投资者设计的 Chrome 浏览器扩展。它以极简的 Apple 股票应用风格，提供 SPY（标普500）和 QQQ（纳指100）的历史数据回测、定投收益计算、年度最大回撤分析以及基于跌幅的机会统计，帮助投资者建立理性的定投策略。

## ✨ 核心功能

1. **实时与历史行情图表**
   - 采用 Apple 风格的红色渐变面积图与底部成交量柱。
   - 支持 1年 / 5年 / 10年 / 全部（All）多时间维度切换。
   - 支持对数坐标轴（Log Scale）切换，更直观地查看长期复利增长。
   - 顶部固定信息条与跟随十字线，提供精确的单日行情反馈。

2. **DCA 定投收益测算**
   - 自定义**每月定投金额**与**起始年份**。
   - 自动测算并对比：总投入本金、期末总市值、定投年化收益率（IRR）、以及等额本金期初一次性投入的收益。

3. **年度最大回撤分析**
   - 自动按年份统计当年的**最大回撤幅度**、**发生日期**以及**回撤修复天数**。
   - 帮助投资者了解各年份的极端市场情况，建立抗风险心理预期。

4. **历史机会（跌幅）统计**
   - 自定义回撤触发阈值（例如 -10%、-20%）。
   - 统计历史触发该跌幅后，未来 3个月、6个月、1年、3年的收益分布（中位数、25%分位数、75%分位数），为抄底加仓提供数据支撑。

5. **双数据源与本地缓存**
   - 优先使用 Yahoo Finance 数据源。
   - 在遇到限流或网络波动时，自动降级至 Stooq 备用数据源。
   - 图表数据支持本地缓存，减少网络请求，支持通过 `Shift + 刷新` 强制清理缓存并拉取最新数据。

## 🚀 安装指南

由于当前为开发者版本，尚未上架 Chrome Web Store，请通过“加载已解压的扩展程序”进行安装：

1. 克隆或下载本仓库代码到本地。
2. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 并回车。
3. 开启页面右上角的 **“开发者模式” (Developer mode)**。
4. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**。
5. 选择本仓库的 `chrome-extension` 文件夹。
6. 安装成功后，点击浏览器工具栏的扩展图标，将“美股定投助手”固定（Pin）在工具栏即可使用侧边栏功能。

## 🛠️ 技术栈

- 原生 JavaScript (ES6+)
- HTML5 & CSS3 (Flexbox/Grid 布局)
- HTML5 Canvas (用于高性能图表渲染)
- Chrome Extension Manifest V3 (Side Panel API)

## 📝 目录结构

```text
chrome-extension/
├── manifest.json      # 扩展配置文件
├── background.js      # 后台 Service Worker，处理点击图标打开侧边栏
├── sidepanel.html     # 侧边栏 UI 骨架
├── styles.css         # 样式表，Apple 风格设计
├── sidepanel.js       # 核心业务逻辑与交互控制
├── utils.js           # 图表绘制 Canvas 引擎与工具函数
└── yahoo.js           # Yahoo Finance / Stooq 数据抓取与解析逻辑
```
